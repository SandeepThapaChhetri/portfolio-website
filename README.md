## 🚀 Getting Started

This is a static site — no build step is required to view it.

1. **Clone the repository**
   ```bash
   git clone https://github.com/SandeepThapaChhetri/sandeep-thapa-portfolio.git
   cd sandeep-thapa-portfolio
   ```
2. **Open the site**
   - Open `index.html` directly in your browser, **or**
   - Serve it with a local server (e.g. the VS Code **Live Server** extension) for
     the best experience.
3. **Editing styles (optional)**
   - Edit `scss/style.scss`, then recompile to `css/style.css` using
     [Prepros](https://prepros.io/) or any Sass compiler.

## ☁️ Deployment

Being a static site, it can be hosted on any static host:

- **Netlify / Vercel / GitHub Pages** — connect this repository for automatic
  deploys on every push.
- **Traditional hosting (cPanel/FTP)** — upload the project contents into
  `public_html`.

Enable HTTPS (free via Let's Encrypt on most hosts) after pointing your domain.

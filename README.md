## Features

- 🎨 Responsive one-page design with smooth scroll navigation
- 🧑‍💻 Home, About, Resume, Services, Skills, Projects, Blog, and Contact sections
- 📊 Animated skill bars and stat counters
- 📱 Mobile-friendly layout with a Bootstrap-based grid
- 📬 Contact section with LinkedIn, Instagram, phone, and email details

## Tech Stack

- **HTML5** & **CSS3** (with **Bootstrap 4** grid/components)
- **SCSS** (compiled via [Prepros](https://prepros.io/))
- **JavaScript / jQuery** — animations, carousels, scroll effects
- Libraries: AOS, Owl Carousel, Magnific Popup, Stellar.js, Waypoints, animateNumber

## Getting Started

This is a static site — no build step is required to view it.

1. Clone the repo:
   ```bash
   git clone https://github.com/SandeepThapaChhetri/sandeep-thapa-portfolio.git
   ```
2. Open `index.html` directly in your browser, or serve it with a local server (e.g. VS Code Live Server) for the best experience.

If you edit `scss/style.scss`, use [Prepros](https://prepros.io/) (or any Sass compiler) to rebuild `css/style.css`.
